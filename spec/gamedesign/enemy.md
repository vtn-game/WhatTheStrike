# 敵キャラ仕様

## 概要

敵はステージ上に配置され、プレイヤーの攻撃対象となる。全ての敵を倒すとステージクリア。

## 対応コード

- `Assets/Scripts/Enemy/Enemy.cs` - 敵キャラのデータと状態

---

## ステータス

| パラメータ | 説明 | 型 |
|-----------|------|-----|
| HP | 体力 | int |
| Attack | 攻撃力（プレイヤーへの接触ダメージ） | int |
| Defense | 防御力（ダメージ軽減） | int |
| Size | 敵のサイズ（Small/Medium/Large/Boss） | enum |

---

## 敵サイズ

```
enum EnemySize {
    Small,   // 雑魚敵（小さい）
    Medium,  // 通常敵
    Large,   // 大型敵
    Boss     // ボス
}
```

---

## ダメージ計算

```
最終ダメージ = プレイヤー攻撃力 - 敵防御力
※最低1ダメージ保証
```

---

## 弱点/属性（拡張用）

```
enum Element {
    None,    // 無属性
    Fire,    // 火
    Water,   // 水
    Wood,    // 木
    Light,   // 光
    Dark     // 闇
}
```

---

## 衝突時の挙動

1. プレイヤーがヒット
2. ダメージ計算
3. HP減少
4. ノックバック（オプション）
5. HP <= 0 で死亡

---

## 死亡処理

1. 死亡アニメーション再生
2. ドロップアイテム生成（拡張用）
3. GameManagerに通知
4. オブジェクト破棄
