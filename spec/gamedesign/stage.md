# ステージ仕様

## 概要

ステージはプレイヤーと敵が配置されるフィールド。壁で囲まれた矩形エリア。

## 対応コード

- `Assets/Scripts/Stage/Stage.cs` - ステージ管理とクリア判定

---

## ステージ構成要素

| 要素 | 説明 |
|------|------|
| 壁（Wall） | ステージ外周の反射壁 |
| 床（Floor） | ステージの床面 |
| プレイヤー配置点 | プレイヤーキャラの初期位置 |
| 敵配置点 | 敵キャラの初期位置 |
| ギミック配置点 | 各種ギミックの配置位置 |

---

## ステージサイズ

```
デフォルトサイズ: 16:9 比率
幅: 18 ユニット
高さ: 10 ユニット
```

---

## クリア条件

```
enum ClearCondition {
    DefeatAllEnemies,  // 敵全滅
    DefeatBoss,        // ボス撃破
    MatchShot,         // マッチショット
    RingBell,          // 鐘を鳴らす
    Custom             // カスタム条件
}
```

---

## ステージデータ形式

```json
{
    "stageId": "stage_001",
    "title": "なんとかストライク",
    "clearCondition": "DefeatAllEnemies",
    "players": [
        { "x": 0, "y": -3 },
        { "x": -2, "y": -3 },
        { "x": 2, "y": -3 },
        { "x": 0, "y": -4 }
    ],
    "enemies": [
        { "type": "slime", "x": 0, "y": 3 }
    ],
    "gimmicks": [
        { "type": "block", "x": 3, "y": 0 }
    ]
}
```

---

## ステージ進行

1. **ステージ開始** - タイトル表示、配置完了
2. **プレイ中** - ターン制でショット
3. **クリア判定** - 条件を満たしたらクリア
4. **結果表示** - クリア/ゲームオーバー
