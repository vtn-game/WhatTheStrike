# 入力回り

## 操作方式
タッチ/マウスドラッグによる引っ張り操作

## 基本操作
| 操作 | 動作 |
|------|------|
| タッチ/クリック開始 | Shootable選択、引っ張りUI表示 |
| ドラッグ | 発射方向・パワー調整 |
| リリース | 発射 |

## InputSystem設定
- Shoot: マウス左ボタン / タッチ
- Pause: Escキー

## 引っ張りUI
- ドラッグ方向の反対に発射
- ドラッグ距離でパワーが決まる
- 最大パワーに上限あり

## 制限事項
- Moving状態のShootableは操作不可
- ポーズ中は全入力無効
- Ready状態のShootableのみ操作可能
