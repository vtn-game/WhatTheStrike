# パフォーマンスチェック

## 概要
インゲームのパフォーマンスチェックを行う

---

## GCAllocを監視する

Profilerを監視し、起動後60f以後にGCAllocが毎フレーム1KB以上ある場合は失敗にする

### チェック項目
| 項目 | 閾値 |
|------|------|
| GC Alloc/frame | < 1KB |
| FPS | >= 60fps |

---

## 物理演算負荷

### チェック項目
| 項目 | 閾値 |
|------|------|
| Shootable 10体同時移動時 | 60fps維持 |
| 衝突判定 100回/frame | < 1ms |

---

## メモリ使用量

### チェック項目
| 項目 | 閾値 |
|------|------|
| ステージロード後 | < 100MB |
| 1ステージ完了後の増加量 | < 10MB |
