# プレイヤーキャラ仕様

## 概要

プレイヤーは4体のキャラクターを操作し、順番にショット（引っ張って発射）を行う。

## 対応コード

- `Assets/Scripts/Player/Player.cs` - プレイヤーキャラのデータと状態
- `Assets/Scripts/Player/PlayerController.cs` - 引っ張り操作とショット制御

---

## プレイヤーキャラ構成

| スロット | 説明 |
|---------|------|
| 1P | リーダー（最初にショット） |
| 2P | サブ1 |
| 3P | サブ2 |
| 4P | サブ3 |

---

## ステータス

| パラメータ | 説明 | 型 |
|-----------|------|-----|
| HP | 体力 | int |
| Attack | 攻撃力 | int |
| Speed | 移動速度係数 | float |
| BumpType | バンプタイプ（反射/貫通） | enum |
| FriendshipCombo | 友情コンボの種類 | enum |

---

## バンプタイプ

```
enum BumpType {
    Reflect,   // 反射（壁や敵に当たると跳ね返る）
    Pierce     // 貫通（敵を貫通する）
}
```

---

## 状態管理

```
enum PlayerState {
    Waiting,    // 待機中（他のキャラのターン）
    Ready,      // ショット可能
    Moving,     // 移動中
    Stopped     // 停止（ターン終了待ち）
}
```

---

## 操作フロー

1. **タッチ開始** - キャラをタッチすると引っ張りUI表示
2. **ドラッグ** - 引っ張り方向と強さを調整
3. **リリース** - 発射
4. **移動** - 物理演算で移動、壁/敵との衝突判定
5. **停止** - 速度が閾値以下で停止、ターン終了

---

## 衝突判定

| 衝突対象 | 動作 |
|---------|------|
| 壁 | 反射 |
| 敵 | ダメージ付与、バンプタイプに応じて反射or貫通 |
| 味方キャラ | 友情コンボ発動 |
| ギミック | 各ギミックの効果適用 |
